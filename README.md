# Auditing Course Shortlists: Reproduction Package

Anonymous reproduction package for the LAK 2027 short paper
"When Agreement Misleads: Auditing Course Shortlists in Curriculum Analytics".

## Contents

| Path | What it is |
|---|---|
| `analysis/core.py` | Signals, combiners, overlap, and the shortlist bound (Proposition 1) |
| `analysis/synth/` | Curriculum simulator (courses, grades, Likert feedback) |
| `analysis/run_study.py` | Runs the simulation study and the real-data audits |
| `analysis/make_paper_assets.py` | Writes the paper tables, macros, and Figure 1 |
| `analysis/prepare_oulad.py` | Builds the OULAD aggregates from the public OULAD files |
| `analysis/test_study.py` | Tests for the bound, signals, and saved results |
| `data/` | Course-level aggregates only (see below) |
| `results/`, `generated/`, `figures/` | Saved outputs used in the paper |

## Reproduce

```bash
pip install -r requirements.txt
python analysis/run_study.py          # under a minute on a laptop
python analysis/make_paper_assets.py
python -m pytest -q analysis/test_study.py
```

The run is deterministic (seeds 43000 to 43029). It regenerates
`results/` and `generated/` exactly.

## Data

- **Local university.** Anonymous course identifiers (`C001` ...), the
  prerequisite graph, per-course failure and enrolment counts for two intakes,
  and a binary five-course reference. No student-level records or real course
  codes are included. The script that built these aggregates from the
  authorised student records is not distributed, because it reads those records.
- **OULAD.** Module-level aggregates derived from the Open University Learning
  Analytics Dataset (Kuzilek, Hlosta, & Zdrahal, 2017; CC BY 4.0). To rebuild
  them, download OULAD and run
  `python analysis/prepare_oulad.py --input <oulad_folder>`.
- **Simulation.** All synthetic data is generated by `analysis/synth/`.
  Its feedback is simulated; no real course feedback is used anywhere.
